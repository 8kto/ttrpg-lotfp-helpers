# Terminology

Owner-defined conventions for RPG terms in user-facing Russian and English text:
[catalogs](../src/translations/locales/) and
[reference pages](../src/translations/pages/). Rule semantics belong to
[domain](domain.md). Existing text that does not follow these tables yet is
tracked in [TODO](../TODO.md).

## RPG mechanics

| Russian                                 | English                           |
| --------------------------------------- | --------------------------------- |
| ХП (inside `HD: ... ХП`)                | HP                                |
| Проверка [ЛОВ/МУД/СИЛ/ТЕЛ/ИНТ/ХАР]      | [DEX/WIS/STR/CON/INT/CHA] Check   |
| преимущество                            | advantage                         |
| помеха                                  | disadvantage                      |
| бонус / штраф                           | bonus / penalty                   |
| хит-поинты                              | hit points                        |
| ЛОВ / МУД / СИЛ / ТЕЛ / ИНТ / ХАР       | DEX / WIS / STR / CON / INT / CHA |
| Монстры с мультиатакой                  | Creatures with multiattack        |
| Doom die / Куб Рока                     | Doom Die                          |
| Usage die (Ud) / Куб Использования (КИ) | Usage Die (Ud)                    |
| Длительный урон                         | Ongoing damage                    |
